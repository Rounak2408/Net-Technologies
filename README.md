# Net-Technologies

This repository contains practical implementations for Net Technologies.

## Directory Structure

*   [Experiment-01](Experiment-01/Program.cs): Student Admission Management System in C#
*   [Experiment-02](Experiment-02/Program.cs): Employee Payroll System using OOP (Inheritance, Interface, Polymorphism) in C#
*   [Experiment-03](Experiment-03/Program.cs): Expense Tracking Module with Exception Handling, CSV Database Persistence and Analytical Reporting in C#
*   [Experiment-04](Experiment-04/Default.aspx): Online Student Event Registration Portal using ASP.NET Controls & Validation
*   [Experiment-05](Experiment-05/Default.aspx): Academic Calendar & Leave Management System using ASP.NET Rich Controls, Session State & Cookies
*   [Experiment-06](Experiment-06/Program.cs): Product Catalog Application using ASP.NET Core MVC Architecture (Controllers, Models, Views, Routing)
*   [Experiment-07](Experiment-07/Program.cs): Feedback Management Module using ASP.NET Core MVC Architecture (Controllers, Models, Views, Partial Views, HTML Helpers, Data Annotations)
*   [Experiment-08](Experiment-08/Program.cs): Inventory Management System using ASP.NET Core MVC, ADO.NET and SQL Server (Full CRUD, Dashboard Analytics)
*   [Experiment-09](Experiment-09/Default.aspx): Placement Management Dashboard using ASP.NET Web Forms, ADO.NET & Data Controls (GridView, DetailsView, FormView, Repeater, DataList)
*   [Experiment-10](Experiment-10/Program.cs): Student Management REST API using ASP.NET Core Web API, Custom Middleware & ADO.NET (REST CRUD, Swagger UI, Request Logging, Timing & Global Exception Handling)
